# Seven Wonders App 🏛️

An Android app that displays the Seven Wonders of the World in alphabetical order, with interactive navigation.

## About
This is a simple learning project created while exploring Android development using **Jetpack Compose** and **Kotlin**.

## Features
- Displays all 7 Wonders of the World
- Each wonder shows:
  - An image
  - Name
  - Place of origin
  - Year of creation
- Navigate using **Next** and **Previous** buttons
- Alphabetically ordered display
- Built entirely with Jetpack Compose

## Tech Stack
- Kotlin
- Jetpack Compose
- Android Studio
